Accessibility Statement

Last updated: January 15, 2026

1 Our Commitment

BPO Hive is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards to ensure we provide equal access to all users.

2 Accessibility Standards

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards. These guidelines explain how to make web content more accessible for people with disabilities and more user-friendly for everyone.

3 Accessibility Features

Our website includes the following accessibility features:

  • Keyboard navigation - All functionality is accessible via keyboard
  • Alt text - Images include alternative text descriptions
  • Color contrast - Sufficient color contrast ratios for text readability
  • Responsive design - Content adapts to different screen sizes and devices
  • Clear headings - Logical heading structure for easy navigation
  • Form labels - All form fields have associated labels

4 Assistive Technologies

Our website is designed to be compatible with assistive technologies including screen readers, screen magnifiers, and speech recognition software. We regularly test our website with popular assistive technologies to ensure compatibility.
