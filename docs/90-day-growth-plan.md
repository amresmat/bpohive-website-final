## KPI dashboard and exclusions

Rows: USA, Canada, UAE, Saudi Arabia, Qatar, Kuwait, Bahrain, Oman, other/unknown; also a GCC subtotal. Keep visitor country separate from declared target market. Group multiple-market submissions explicitly. Columns: prospect sessions, sessions reaching booking, form starts, successful qualified submissions, confirmed booked calls, held calls, accepted opportunities, ad spend and cost per booked call. Dimensions: date/week, first landing page, session source/medium/campaign, device and country. Deduplicate bookings by appointment identifier; cancellations and reschedules need reconciliation. Never send names, emails, websites or Calendly invitee URLs to GA4.

Definitions: prospect sessions are sessions in target geographies excluding recruitment-intent sessions; this is a useful proxy, not proof every visitor is a buyer. Booking-page rate = booking-page sessions / prospect sessions. Start-to-submit = successful submissions / form starts. Cost per booked call = attributable channel spend / confirmed new booked calls; show “—” for zero denominator. Report paid CPBC separately from blended marketing cost including labor. Website calendar-open events are not bookings.

Month-three monthly operating targets: USA 300 prospect sessions / 60 booking-page sessions / 30 starts / 6 booked calls; Canada 100 / 20 / 10 / 2; GCC combined 350 / 70 / 35 / 7. Total 750 / 150 / 75 / 15 versus user baseline ~250 prospect sessions and 32 booking-page visits. Paid target: 8 confirmed qualified calls for $2,500 = $312.50 CPBC; total 15 calls are not all attributed to ads. These are targets to test, not traffic or conversion guarantees. Review by region weekly, but avoid decisions on a single conversion.

GA4: Explore → Free form/Funnel → create a SESSION segment “Commercial target markets”. Include target countries. Exclude sessions where Page path and screen class matches `^/(careers|work-with-us|form-received)(/|\\.html|$)`. Use session-scoped exclusion so later non-career pageviews in a recruitment session do not contaminate the report. For page-only content reports, add the same regex as a page exclusion. Keep a separate recruitment report. Do not use GA4 internal-traffic data filters for URL filtering. Create event-scoped custom dimensions for `target_market`, `funnel_path`, `budget_band`; register custom events in GTM and check DebugView. Mark only confirmed booked calls as the primary acquisition key event.

Mouseflow: create a saved commercial segment excluding sessions containing /careers, /work-with-us and /form-received. Confirm its count using known career sessions. Keep a separate careers segment to measure the reported 17% dead-click baseline against the mobile fixes. If the current plan/UI lacks session-level URL exclusion, use a custom recruitment-intent variable/tag and exclude that segment; do not silently use a page-only filter and call it session isolation. Mask all form inputs and exclude Calendly query parameters from recordings. Review keyboard, mobile modal opening/closing and the sticky Apply action. Reduced dead-click rate requires subsequent observed recordings; deployment alone cannot prove it.
